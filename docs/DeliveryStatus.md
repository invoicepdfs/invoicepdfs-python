# DeliveryStatus

Email delivery. `sent` is terminal success — nothing reports back what the provider did with the message after we handed it over.

## Enum

* `QUEUED` (value: `'queued'`)

* `SENT` (value: `'sent'`)

* `FAILED` (value: `'failed'`)
